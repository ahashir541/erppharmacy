Nuskha for Windows

This is Nuskha Local, for Windows 10 and 11 (64-bit). Install it on the main PC of your pharmacy; other counters join over the shop's Wi-Fi.

  1. Open the downloaded Nuskha.zip and choose Extract all.
  2. In the Nuskha folder, right-click Install-Nuskha.ps1 → Run with PowerShell. For more counter PCs, use Run as administrator once.
  3. If Windows asks "Do you want to run this?", choose Run. Nuskha opens by itself and starts every time the PC starts.
  4. Choose Set up my pharmacy, then enter the licence key we send you. You'll see Licence key verified.
