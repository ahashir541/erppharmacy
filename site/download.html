Nuskha for Windows

This is Nuskha Local, a Windows program for Windows 10 and 11 (64-bit), with its own window and desktop icon. Install it on the main PC of your pharmacy; other counters join over the shop's Wi-Fi.

Download Nuskha · 52 MB

  1. Open the downloaded Nuskha.zip and choose Extract all.
  2. In the Nuskha folder, right-click Install-Nuskha.ps1 → Run with PowerShell. For more counter PCs, use Run as administrator once.
  3. If Windows asks "Do you want to run this?", choose Run. Nuskha opens in its own window and starts every time the PC starts. Next time, open it from the Nuskha icon on the desktop.
  4. Choose Set up my pharmacy, then enter the licence key we send you. You'll see Licence key verified.
