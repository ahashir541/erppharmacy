Download Nuskha for Windows

This is Nuskha Local, a Windows program for Windows 10 and 11 (64-bit), with its own window and desktop icon. Install it on the main PC of your pharmacy; other counters join over the shop's Wi-Fi.

Download NuskhaSetup.exe · 52 MB

Or the zip (Install-Nuskha.ps1 inside) · Version 1 (beta) · SHA-256 of NuskhaSetup.exe 15948ab19cddfbcd92ef86edc513b6413b8be38d445a38312429ec14ff67c791

  1. Double-click NuskhaSetup.exe. If Windows says "Windows protected your PC", click More info → Run anyway, then Yes.
  2. Press Install. About a minute later Nuskha opens in its own window, and starts every time the PC starts.
  3. Choose Set up my pharmacy: your pharmacy, the owner and this counter. Enter the licence key we send you.
  4. Read the step-by-step guide: staff, other counters, WhatsApp and backups.
